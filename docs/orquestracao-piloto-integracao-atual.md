# Orquestração global no Phoenix ONE oficial
Sem restrição de telefone; usa a API, Bridge, modelo e RAG existentes. Padrão inicial Clara + Murilo, revisão 1. Primeira seleção Somente Clara define corte para a próxima meia-noite em America/Sao_Paulo; novos protocolos passam a usar a estratégia selecionada após o corte. Protocolos antigos permanecem duais; pós-corte, pin por base imutável e sufixos herdam. Configuração exclusiva de admin autenticado. A flag PHX_ORCHESTRATION_PILOT_ENABLED=false é desativação emergencial, não configuração padrão.
A chamada de pin substitui a consulta intro_status no fluxo novo, preservando a mesma persistência de saudação e bloqueio de protocolo. Sem PII nova nas tabelas. Dados de teste reais não isolados; usar dados fictícios e modo sugestão. RAGs, prompts, MegaBrain e Junior não alterados.
